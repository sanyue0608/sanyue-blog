这是这个博客的第一篇文章。

建这个站花了点时间，但真正难的部分其实不是技术——是想清楚「我为什么要有一个自己的地方」。答案很简单：有些话说完了会散，有些想法不写下来就没了。我想要一个不会被算法决定顺序、也不会被平台随时关掉的角落。

## 这里会有什么

大概三类：

- **技术笔记**：踩过的坑、读完文档之后的整理。写给别人看之前，先写给自己。
- **生活碎片**：某天的天气、某个忽然的想法，短一点的那种。
- **长期的东西**：一个会慢慢变长的系列，而不是发完就沉下去的单篇。

## 关于这个站

它用 [Astro](https://astro.build/) 构建，主题是开源的 [Shirone](https://github.com/LyraVoid/Shirone)。选它是因为两件事：

1. **静态站点**——页面在你打开之前就已经生成好了，所以很快，也不需要数据库和服务器维护。
2. **写作体验好**——Markdown 直接写，公式、代码、图表都能用，不用为了排版跟编辑器打架。

:::note
下面这段是给未来的自己看的备忘：本站的文章源文件都在 `src/content/posts/`，
写一篇新文章只需要 `pnpm new-post 文件名`，然后编辑生成的 `.md` 文件。
:::

## 一个小例子

比如代码块，写起来是这样：

```ts
// post.frontmatter 里填的那些字段，决定了文章出现在哪里、以什么顺序
export const greeting = (name: string) => `你好，${name}`;

greeting("世界"); // "你好，世界"
```

数学公式也没问题：

$$
\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}
$$
