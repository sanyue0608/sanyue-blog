# 关于我

你好，我是**叁月**。

这里是我的个人博客，用来放一些写下来会更好的东西：读完一本书之后的整理、踩过的坑、某个下午忽然冒出来的想法。

## ✦ 关于这个站

这个站是用 [Astro](https://astro.build/) 加开源主题 [Shirone](https://github.com/LyraVoid/Shirone) 搭起来的静态博客：

- **没有数据库**：所有页面在构建时生成成 HTML，所以打开很快，也不用维护服务器。
- **文字优先**：文章就是 Markdown 文件，写在本地，不依赖任何编辑器或后台。
- **自己的地方**：没有推荐流，没有排序算法，想写什么写什么。

## ✦ 技术栈

- **框架**：[Astro 7](https://astro.build/) + [Svelte 5](https://sveltejs.dev/)
- **样式**：[Tailwind CSS 4](https://tailwindcss.com/) + [Stylus](https://stylus-lang.com/)
- **设计规范**：[Material 3 Expressive](https://m3.material.io/)
- **搜索**：[Pagefind](https://pagefind.app/) 本地全文检索
